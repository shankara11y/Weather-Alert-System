# Weather Alert System 🌦️

A Python-based Weather Alert System that monitors temperature, humidity, and rain probability,
generates alerts for extreme conditions, stores weather data, and visualizes trends.

## Features
- Object-Oriented Programming
- CSV & JSON file handling
- Alert system using decorators
- Temperature classification using lambda
- Data visualization with matplotlib

## How to Run
```bash
pip install matplotlib
python weather_alert_main.py
